# 강의녹음

강의를 녹음하고 Gemini API로 txt 전사본을 만드는 안드로이드 앱.

## 설치
1. 저장소의 Releases에서 최신 `lecture-recorder.apk`를 폰으로 받는다.
2. 열어서 설치한다. "출처를 알 수 없는 앱" 허용을 물으면 허용한다.
3. 새 버전도 같은 방법으로 받아서 덮어 설치하면 된다(녹음은 유지됨).

## 처음 설정
- 앱 → 설정 → Gemini API 키 입력 (aistudio.google.com 에서 발급, 각자 자기 키)
- 과목 일정: `과목,시작일,종료일` 한 줄씩. 오늘 날짜의 과목이 기본 선택된다.
- 전사 모델: 위에서부터 사용. 기본값은 Flash 계열만.

## 동작
- 녹음: 화면을 꺼도 계속된다. 파일 이름 `과목_YYMMDD_HH시MM분.m4a`.
- 녹음을 멈추면 인터넷 연결 시 자동 전사.
  - 약 10분 단위, 조용한 지점에서 자르고 앞뒤 15초 겹쳐 보낸다.
  - 모델이 바쁘면 대기 후 재시도 → 다음 모델 → 그래도 안 되면 나중에 자동 재시도.
  - 분량이 적거나 타임스탬프가 90초 이상 비면 그 조각만 다시 전사.
  - 끝까지 의심되면 본문에 `[누락 의심 mm:ss–mm:ss]` 표시.
- 목록에서 "녹음 공유", "전사본 공유"로 드라이브에 올린다.

## 빌드
`main`에 푸시하면 GitHub Actions가 APK를 빌드해 Releases에 올린다.
